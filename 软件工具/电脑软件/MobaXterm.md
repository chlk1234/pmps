[官方地址](https://mobaxterm.mobatek.net/) 
MobaXterm 是一款专为 **Windows 系统**设计的 **一体化终端与远程连接工具**，由法国公司 **Mobatek** 开发。它集成了多种开发者、系统管理员和网络工程师日常所需的工具于一身，被誉为 Windows 平台上的“**瑞士军刀式终端软件**”。

#### **强大的本地终端（Local Terminal）**

- 基于 **Cygwin** 环境，内置 **100+ 个 Linux/Unix 命令**（如 `ls`、`grep`、`awk`、`sed`、`rsync`、`wget` 等）
- 支持 **Bash shell**，让你在 Windows 上像使用 Linux 一样操作
- 可运行 Python、Perl、Shell 脚本等
#### **多协议远程连接（All-in-One 远程客户端）**

| 协议 | 用途 |
|------|------|
| SSH | 连接 Linux 服务器（最常用） |
| SFTP / FTP | 文件传输（连接 SSH 后自动弹出图形化文件浏览器） |
| RDP | 远程桌面连接 Windows 主机 |
| VNC | 控制远程图形桌面 |
| Telnet / Rlogin | 传统网络设备管理 |
| Serial（串口） | 调试单片机、路由器等硬件设备 |
| Mosh / XDMCP / WSL | 其他高级连接方式 |

#### **X11 图形转发（杀手级功能）**
- 内置 **X Server**，无需额外安装
- 可直接在 Windows 上显示并操作 **Linux 服务器的图形界面程序**（如 `gedit`、`xclock`、甚至 `firefox`）
#### **可视化文件传输**

- SSH 登录后，**左侧自动弹出 SFTP 面板**
- 支持 **拖拽上传/下载**，无需记忆 `scp` 或 `rsync` 命令
- 文件目录可与终端当前路径 **自动同步**

#### **高效会话管理**

- 所有连接配置（IP、账号、密钥等）可保存为“会话”
- 支持文件夹分类、批量启动、桌面快捷方式
- 内置 **密码管理器**（加密存储，需设主密码）

#### **其他实用工具**

- 内置 **文本编辑器**（带语法高亮，双击远程文件即可编辑）
- **宏录制**：自动重复操作
- **端口扫描、网络监控、Ping 工具**
- **多标签页 + 分屏**（支持 2/4 分屏、横向/纵向）
- **Multi-execution 模式**：向多个服务器同时发送相同命令

#### **多种版本选择**
| 类型 | 特点 | 适用场景 |
|------|------|--------|
| Portable（便携版） | 解压即用，所有配置存在本地文件夹，可放 U 盘随身携带 | 多电脑切换、无管理员权限、注重隐私 |
| Installer（安装版） | 标准安装，集成到开始菜单，支持自动更新 | 固定电脑长期使用 |
> [!note]
> 💡 免费版（Home Edition）已满足绝大多数个人和小团队需求；专业版（Professional）提供更多企业级功能（如 LDAP 集成、定制部署等）。


一个工具满足
相比 PuTTY + FileZilla + Xming 等组合：

- **一个软件替代多个工具**
- **零配置实现 X11 转发**
- **SFTP 与终端无缝联动**
- **开箱即用的 Unix 命令环境**
> [!note]
> 🌰 例如：你只需点击一次 SSH 会话，就能同时获得命令行 + 文件浏览器 + 图形程序支持，效率大幅提升。


**MobaXterm = SSH 客户端 + SFTP 文件管理 + X Server + Linux 命令行 + 远程桌面 + 串口调试 + 网络工具箱**  
是 Windows 用户进行 **远程运维、开发、嵌入式调试** 的理想选择。
