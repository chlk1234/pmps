[Captura](https://github.com/MathewSachin/Captura)**是**一款适用于 Windows 的屏幕截图（包括屏幕截图和录制）应用程序，可以捕获屏幕、摄像头、音频和键盘输入。**它已停止维护**，但[源代码仍然存档在 GitHub 上，](https://github.com/MathewSachin/Captura)拥有超过 8000 个 star 和 1500 多个 fork。
主要功能有：
- 截屏
- 录制屏幕视频（AVI/GIF/MP4）
- 带/不带鼠标光标的截图
- 捕获特定区域、屏幕或窗口
- 捕获鼠标点击或键盘输入
- 混合录制自麦克风和扬声器输出的音频
- 通过网络摄像头拍摄。
- [可通过命令](https://mathewsachin.github.io/Captura/cmdline)行使用（_测试版_）。
- 提供[多种语言版本](https://mathewsachin.github.io/Captura/translation)
- 可配置[热键](https://mathewsachin.github.io/Captura/hotkeys)


Captura 是一款面向 Windows 平台的免费、开源屏幕录制软件。它以其轻量级、功能丰富和高度可定制性而受到欢迎，旨在为用户提供一个简单易用且强大的屏幕、摄像头及音频捕捉解决方案。无论您是需要制作教学视频、录制游戏过程、演示软件操作，还是进行远程技术支持，Captura 都能提供有效的帮助。
## 主要特性
- **多种录制模式:** 支持全屏录制、特定窗口录制、指定区域录制以及针对游戏的 DirectX 全屏录制模式。
- **摄像头与音频捕捉:** 可以同时或单独录制来自网络摄像头、麦克风以及系统播放的声音。用户可以灵活配置音频来源。
- **丰富的输出选项:** 支持多种视频格式和编码器，包括 MP4 (使用 H.264, H.265/HEVC, AV1 等编码器，可通过 FFmpeg 支持更多)、AVI、GIF 动图等。用户可以根据需求调整帧率 (FPS)、视频质量和编码器设置，平衡文件大小和清晰度。支持利用硬件加速编码（如 Intel QSV, Nvidia NVENC, AMD AMF）以降低 CPU 占用。
- **实用辅助功能:**
    - **鼠标与键盘高亮:** 可在录制时显示鼠标点击效果和按键记录，非常适合制作操作教程。
    - **水印添加:** 支持在视频中添加自定义的图像或文本水印。
    - **定时录制:** 可以预设录制的开始和结束时间，实现自动化录制。
    - **热键支持:** 提供丰富的可自定义快捷键，方便在录制过程中快速控制开始、暂停、停止、截图等操作，支持热键覆盖，即使在全屏应用中也能响应。
- **开源与免费:** Captura 基于 MIT 许可证开源，完全免费，没有任何功能限制或水印（除非用户自行添加）。用户可以查看和修改源代码。
- **命令行界面 (CLI):** 支持通过命令行参数进行控制，方便集成到自动化脚本或工作流中。
- **多语言支持:** 提供包括简体中文在内的多种界面语言。
