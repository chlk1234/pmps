
# 1.国家智慧教育公共服务平台
[国家智慧教育公共服务平台](https://www.smartedu.cn/) 很多人都不知道这个网站，但是这个网站是真的超级好用，可以堪称教育资源大宝库。这是国家队的超级教育平台，这个2022年3月才正式上线的国家级综合教育公共服务平台，可能目前还有很多人不知道，但是该平台目前已有注册用户已超1.69亿，页面浏览量突破646亿次，服务范围超过220多个国家和地区。

平台主要目标是通过数字化手段促进教育公平与质量提升，希望构建一个“人人皆学、处处能学、时时可学”的学习环境。平台功能非常全，覆盖了基础教育、职业教育、高等教育和终身教育的优质资源，包括中小学资源11万余条、职业教育精品课程1.13万余门、高等教育在线课程3.1万门以及终身学习课程超2000门。而且它还集成了就业、考试、学历认证等8大类51项服务。

包括最新最火的AI人工智能资源也有很多，另外很多人各种找中小学的教材，但是不知道这上面全部都免费下载，而且各省各地教材均有，非常全面。

# 2.mvnrepository Maven仓库聚合

[mvnrepository](http://mvnrepository.com) 这是我最常用的一个网站，是一个Maven仓库聚合网站，这里聚合了几乎所有主流Java用到的maven仓库，可以说是汇集了整个Java生态的代码仓库。这样不用每个maven仓库都去查找。我主要经常用来查一些Maven库的版本，选择合适的版本，尽量避免漏洞较多的版本和有高危漏洞的版本， 通常会选择最新的版本和下载量较多的版本。然后一键复制将依赖引入到我的项目中。

# 4.ProcessOn在线设计作图平台

[processon](https://www.processon.com/)  ProcessOn 是一款专业强大的作图工具，支持多人实时在线协作，可用于甘特图、ER图、UML、网络拓扑图、鱼骨图、组织结构图等多种图形绘制。这是国内做的比较好的在线作图工具。有很多丰富的图标以及丰富的模版。个人可以免费使用，但是个人免费用户限制文件数，而且确实有点少。免费用户现在限制比较多，不过收费也不算贵，有条件的还是可以用收费的。
![image.png](https://cdn.jsdelivr.net/gh/xtcn92/zhpic@image/20251222171905896.png)

# 5.draw.io专业在线作图

[draw.io](http://draw.io/)现在会自动跳转到 http://diagrams.net 。是ProcessOn的平替。 是一款完全免费且功能全面的图表绘制网站。既可以在线直接使用也提供客户端，且支持Mac、Windows、Linux版本。支持的图形也很多，包括流程图、UML图、网络拓扑图、组织结构图、思维导图等多种图。内置图形符号种类丰富，基本上满足日常设计需求。我日常主要用来做架构设计画图。不过有一说一，图标美观性差点意思，而且不怎么更新。不过胜在免费，且限制比较少，灵活度很高，而且支持将文件存在Github、GitLab、Google Driver、和本地硬盘上。真的非常人性化。
